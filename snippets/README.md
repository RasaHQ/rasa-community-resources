# Snippets

Short pieces of code or config that are useful to practitioners but too small to be a [pattern](../patterns/).

This folder is **accepting contributions**. There are no top-level snippets checked in yet.

(Note: many examples already keep **tutorial paste-ready files** under their own `tutorial/snippets/` trees. Those stay with the example or tutorial. This folder is for standalone fragments that are not part of a larger resource.)

---

## What belongs here

- A single technique or fragment with a short README explaining when to paste it
- Something others would search for by name (e.g. a memory schema shape, a Makefile target, a verify-script stub)

## What does not belong here

| Instead put it in… | When… |
|---|---|
| [`patterns/`](../patterns/) | The fragment needs surrounding explanation and a reusable structure |
| [`examples/`](../examples/) / [`tutorials/`](../tutorials/) | It only makes sense inside a full agent or walkthrough |
| An example’s `tutorial/snippets/` | It is a chapter paste file for that project’s live session |

---

## Naming

Prefer a descriptive slug with no spaces:

```text
<what-it-does>
```

Examples: `skill-local-tools-stub`, `deepgram-inspector-env`.

## How to add a snippet

1. Follow [CONTRIBUTING.md](../CONTRIBUTING.md).
2. Start from [docs/RESOURCE_TEMPLATE.md](../docs/RESOURCE_TEMPLATE.md) (keep the README short).
3. Replace the empty catalog row with your entry.
4. Area review: [MAINTAINERS.md](../MAINTAINERS.md).
