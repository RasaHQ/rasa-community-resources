description: Read permitted fictional account information or review a transfer.

Use @tool.banking_accounts to list permitted aliases.
Use @tool.banking_balance for a service-supplied balance.
Use @tool.banking_history, @tool.banking_loan_payment and @tool.banking_payoff
only for the corresponding request. State unsupported results without guessing.
Use @tool.banking_review_transfer to produce a canonical own-account review.
The host, not a model boolean, observes the next explicit confirmation turn.
Only @tool.banking_submit_transfer can submit; it refuses without host proof.
Use @tool.banking_transfer_status for the original outcome, never a second write.
Never claim accepted or queued means posted. Keep private codes out of speech.
