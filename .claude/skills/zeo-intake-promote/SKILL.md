# zeo-intake-promote

1. `zeo intake mission <path> --json`
2. Inspect repository bytes
3. `zeo intake propose <path> --spec <proposal.json>`
4. `zeo intake promote <path>`
Never author SOW YAML or choose `n` yourself.
