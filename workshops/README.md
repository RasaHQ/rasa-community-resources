# Workshops

Slides, exercises, and solutions from community sessions and conference workshops.

This folder is **accepting contributions**. There are no workshop packs checked in yet.

---

## What belongs here

- Material tied to a **delivered or scheduled session** (meetup, conference, internal enablement)
- Exercises with clear timing and, where possible, solutions or facilitator notes
- A README that states audience, duration, and what participants need installed beforehand

## What does not belong here

| Instead put it in… | When… |
|---|---|
| [`tutorials/`](../tutorials/) | An always-on self-serve walkthrough, not a timed session |
| [`examples/`](../examples/) | A finished agent without workshop packaging |
| [`patterns/`](../patterns/) | A reusable technical reference without classroom structure |
| [`snippets/`](../snippets/) | Loose fragments without session framing |

---

## Naming

Prefer:

```text
<event-or-topic>-<year>
```

Examples: `voice-skills-pycon-2026`, `handoff-patterns-meetup`.
