The scripts that produced the recorded runs, as they ran. `run_claude_experiment.sh` made the nine Claude Code runs. `run_one_codex_and_claude.sh` made the nine Codex runs (called nine times from a loop `for n in 1 2 3; for t in a1-block-card a2-rule-digits a3-rule-confirm; ./run_one.sh codex tasks/$t.json $n`); it holds a hard-coded path to the author's machine and is a record, not a tool. One line differs from what ran: `run_one_codex_and_claude.sh` had a no-op `for k in OPENAI_API_KEY RASA_LICENSE; do :; done` that looked like a scrub and did nothing; it is now a comment saying how the agents authenticated (their own stored sign-in; `OPENAI_API_KEY`, `RASA_LICENSE` and `ANTHROPIC_API_KEY` were unset in the shell when checked). The Claude Code script was started with `env -u CLAUDECODE -u CLAUDE_CODE_ENTRYPOINT ...` from a detached tmux session.
