Start with the travel-agent illustration in the deck. Say it is an illustration. If you have a recording from a real rehearsal, show that and name its date. This package does not contain a new recording.

For an installed, licensed travel scaffold, the labeled replay path is:

```bash
cd book/ready/ch00/demo
BRIEFING_RECORDED=1 make run-scripted
```

Follow the exact recorded prompts in chapter 0. SCRIPTED describes tool selection; REPLAY describes the source data. Neither demonstrates live speech or a live builder.

If the engine cannot start, use the standard-library recovery exercise in Track B of `PARTICIPANT-GUIDE.md`. Show ACCEPT, a rejected baseline, and a duplicate request that performs no extra work.
