Your setup, in eight steps

One action per step. Do them in order and you will have your first live result in about ten minutes.

0

Bring three things

Laptop with Chrome, headphones with a mic, a GitHub account (free: github.com/signup).

1

Get your Rasa licence

Request it at rasa.community/#request-license. The email takes a few minutes, so start here. Copy the whole string.

2

Get your OpenAI key

Ask the Rasa team for one. We hand out the keys at the workshop. Copy yours and keep it private.

3

Get your Deepgram key

Sign up or log in at console.deepgram.com. Settings → API Keys → Create a New API Key. Copy it.

4

Save all three on GitHub

github.com/settings/codespaces → New secret. Name, value, Add secret. Three times:

RASA_LICENSE  ·  OPENAI_API_KEY  ·  DEEPGRAM_API_KEY

In Repository access, type rasa-community-resources and pick RasaHQ/rasa-community-resources.

5

Open the workshop

Scan the code, or open github.com/RasaHQ/rasa-community-resources and click the Codespace link. Pick Rasa Travel Agent Factory, 4-core, Create codespace.

You seeTravel factory dependencies ready.
github.com/RasaHQ/rasa-community-resources
6

Check your keys

Terminal → New Terminal. Type bash desk doctor, press Enter.

You seethree names, each present.
7

Your first win

Type bash desk data fx USD GBP 200, press Enter.

You seeconverted and reference_date.
Stuck?

A name says missing: fix its spelling or Repository access in step 4. Then github.com/codespaces → … → Stop codespace, reopen it, rerun step 6. Anything else: raise your hand. The host gave you a value? Use it in that step. Full guide: the workshop README.
