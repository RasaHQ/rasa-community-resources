Proven once by rasa-bench on Nov 2, 2026 with the Rasa CLI 3.21.0.dev5 from the Mantle environment, against Studio 1.15.2 (model service 3.15.8), inside the codespace, SSL verification on:
rasa studio config --advanced, answers in this order:
  Studio URL:     http://localhost:4000
  Keycloak URL:   http://localhost:8081/auth/
  Realm:          rasa-studio     (the default, press Enter)
  Client ID:      admin-cli       (the default, press Enter)
  exit 0
rasa studio login   with the documented Studio user superuser  -> Login successful, exit 0
rasa studio upload NAME   (positional name, no --dangerously-delete-existing)  -> Upload successful, exit 0
Timing: the upload request took 3.2 seconds; the whole CLI call 11.8 seconds. Config and login were not separately timed.
The default config (Studio URL http://localhost:8080) does not work: it derives Keycloak at http://localhost:8080/auth/.
