# Reference material — fictional

The two documents in this directory are what the FAQ skill answers from. They
describe a **fictional** municipal complaint line.

The localities and PIN codes named in them are real Ghaziabad ones, so the demo
sounds plausible to someone who knows the city. Everything else — ward numbers,
officer names, department names, phone numbers, target times and the escalation
ladder — is invented for this project.

No routing or service data here came from a real municipal authority, and
nothing should be relied on as a description of a real municipal service.

| File | What it covers |
|---|---|
| `how_the_line_works.md` | Scope, what to have ready, target times, checking a complaint, escalation |
| `about_this_demo.md` | That this is a demonstration and reaches no municipal system |
