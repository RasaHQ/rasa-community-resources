# Reference material

The documents in this directory are **synthetic reference material** provided
for demonstration purposes only. All examples, sample values and narrative
contents are **fictional** and **invented**: they are illustrative fixtures
used to seed the TerraEnergy assistant's reference embeddings, and are not
real reports, real measurements, or real vendor documentation.

Anyone running the TerraEnergy open-source example is expected to replace
these fixtures with their own curated reference content.
